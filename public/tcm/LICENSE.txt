中医药歌诀库（public/tcm/tcmchants.json.gz）数据说明
====================================================

本目录的数据由 scripts/fetch-tcmchants.mjs 从上游拉取并转码生成，
**不随仓库分发**（.gitignore 已排除 *.gz）。首次使用请运行：

    npm run tcmchants:fetch        # 或 npm run tcmchants:check 仅校验现有快照

许可：同上，仓库未声明许可证；古籍原文属公有领域。

《药性歌括四百味》（明·龚廷贤，366 条）主源缺书，取殆知阁「医藏」目录下
该文件（UTF-8）为底本。此版本存在条目粘连与缺字缺陷，处理原则是**不猜字**：
  - 粘连：按勘误表在已知边界（下一条药的通行首句）拆开，共 20 处；
  - 缺字：保留全角空格占位并标「存疑」注，如「黄　性温」标题勘正为黄芪；
  - 版本收录条数与通行本（388/400 味）存在出入，页面已注明「以通行校点本为准」。

------------------------------------------------------------------
本项目所做的加工（均可由脚本复现）
------------------------------------------------------------------
1. 编码转码：GB18030 → UTF-8；jsDelivr 超包限额会返回 200 + 错误说明文本，
   体积下限校验是硬拦截，raw.githubusercontent 作兜底镜像。
2. 结构解析：<篇名>/<目录>/属性： 标记转成 { 书 → 分组 → 条目 } 三级结构；
   医学三字经按 \x 成对标记提取韵文正文、余文作注。
3. 占位符清洗：\x 校验残迹剥除、KT 缺字占位与 U+FFFD 统一为全角空格。
4. 韵文 / 注文分离：歌诀本体进 verse（背诵界面用），夹注、主治、组成、
   炮制畏恶、蔚按等按语进 note（阅读界面呈现）。

------------------------------------------------------------------
校验
------------------------------------------------------------------
scripts/fetch-tcmchants.mjs 在生成与 --check 时都会断言：
  - JSON 可完整解析（下载被截断会在此拦下）
  - 八书条数下限（汤头≥170、濒湖≥24、药性歌括≥320 等）
  - 韵文非空、含汉字、无 CR、无 \x / KT 占位残留
  - 正文总字数 ≥ 20 万
  - pack → unpack 往返逐字段等价

产物约 273 KB（gzip），1143 条 / 22.7 万字。
